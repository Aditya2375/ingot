Two independent nodes running the real consensus code, compiled to WebAssembly. Create wallets, mine blocks, send coins, cut the link to fork the chain, then sync and watch the most-work rule reorganize the shorter branch. Demo coins have no value. Wallet seeds have only 32 bits of entropy and must never be reused for real assets. Reloading discards all state. Everything runs locally - the same chain.c the native node uses. source
